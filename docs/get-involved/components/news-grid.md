## NewsCard

The news card: banner thumbnail, date, primary category badge, headline, summary, and a footer with the author next to where the card leads.

It is the single card in the news area. Both consumers render through it, so the card markup and the category colors exist once:

| Consumer | What it passes |
|---|---|
| `NewsGrid` (news listing) | The post's whole summary, and the link to the original article on the publisher's site |
| `LatestNewsSection` (homepage) | The summary clamped to three lines, and the link to the post's own page |

## NewsGrid

The news listing: one card per post of the current page, two cards per row, paginated server-side.

It is used by the swizzled `BlogListPage` and `BlogTagsPostsPage`, so `/news`, `/news/page/<n>`, and every tag page render the same grid.

### Basic Usage

From `src/theme/BlogListPage/index.js`:

```jsx
import NewsGrid from '@site/src/components/NewsGrid';

<NewsGrid items={items} />;
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `Array` | - | The blog list items the theme passes to the page (`[{content: BlogPostContent}]`). The grid renders exactly the posts the current page owns, so pagination and the post order stay in the hands of the blog plugin. |

## NewsCard props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `post.title` | `string` | - | Headline. |
| `post.date` | `string` | - | Any date the `Date` constructor accepts; rendered as `September 4, 2026`. |
| `post.category` | `string` | - | Category slug, used for the badge color via `data-category`. |
| `post.categoryLabel` | `string` | - | Badge text. The badge is omitted when it is empty. |
| `post.image` | `string` | - | Thumbnail, resolved through `withBaseUrl`. An empty value renders the image slot without an image, so the card keeps its proportions. |
| `post.description` | `string` | - | Summary text, omitted when empty. |
| `post.author` | `{name, imageUrl}` | - | Author footer. The avatar is omitted when `imageUrl` is missing. |
| `post.href` | `string` | - | Destination of the whole card. |
| `post.external` | `boolean` | `false` | Opens in a new tab with `rel="noopener noreferrer"` and marks the footer with an arrow. |
| `post.clampDescription` | `boolean` | `false` | Cuts the summary to three lines, for grids whose cards share a fixed height. Trims to whole words by measuring the rendered height, because the plain CSS clamp cuts at the line edge and lands mid-word. The server-rendered HTML keeps the full text. |
| `className` | `string` | - | Extra class on the card root, used by `LatestNewsSection` to hide the fourth card onwards on small screens. |

## How a card gets its content

Titles, permalinks, dates, and tag labels come from the blog plugin. The extras come from `src/data/newsIndex.json`, generated by `yarn build-news`:

| Card element | Source |
|---|---|
| Thumbnail | `image` from `newsIndex.json`, else the category image from `src/data/newsCategories.js` |
| Summary | `description` from `newsIndex.json` (a word-boundary cut of the post's own text), else the post's meta description |
| Badge | The post's first tag, which is the most specific one by convention |
| Date | The post's date, formatted as `September 4, 2026` |
| Author | `authors` from `newsIndex.json`, else the theme's post metadata |

The lookup is keyed by slug rather than by full permalink, so it also resolves on the localized blog routes. The summary in `newsIndex.json` is capped at 600 characters only to keep outlier paragraphs out of the page bundle.

## Where a card leads

Cards in the listing link to the original article, not to the post's page on cardano.org: the site is a hub, so the grid is an entry point to the sources. The link opens in a new tab and carries `rel="noopener noreferrer"`. Posts whose body carries no external link fall back to their own page; two posts do that today (the weekly development reports of 12 and 26 January 2024).

The post pages themselves stay in place and stay in the sitemap: they are what a search visitor lands on, with their own title, meta description, and canonical URL.

## Notes

- Two columns above 996px, one below that.
- Eight cards per page (`postsPerPage` in `docusaurus.config.js`): four rows of two. Every card carries the post's whole summary, so a longer page would get very long.
- Cards in a row are stretched to a shared height by the grid, so uneven summary lengths stay tidy.
- Only posts that carry a banner image in their body get a thumbnail of their own. Everything else falls back to the category image.
- The "Read more" label reuses the homepage string (`latestNews.readMore`), so the wording is translated once.
